# MARA Roadmap                                                                                                               
                                                                                                                               
  This repository tracks feature requests, bug reports, and planned improvements for [MARA](https://maraiq.com) — the maritime 
  security intelligence platform.                                                                                              
                                                                                                                               
  ## View the Roadmap                                                                                                          
                                                                                                                               
  **[View the Roadmap Board →](https://github.com/orgs/atlas-bear/projects/3)**                                                
                                                                                                                               
  The board shows the status of all submitted feedback:                                                                        
                                                                                                                               
  | Column | Meaning |                                                                                                         
  |--------|---------|                                                                                                         
  | **Inbox** | New submissions awaiting review |                                                                              
  | **Triaged** | Reviewed and prioritized |                                                                                   
  | **Planned** | Scheduled for development |                                                                                  
  | **In Progress** | Currently being built |                                                                                  
  | **Done** | Shipped |                                                                                                       
                                                                                                                               
  ## Submit Feedback                                                                                                           
                                                                                                                               
  Feedback is submitted directly from within the MARA app:                                                                     
                                                                                                                               
  1. Log in to [MARA](https://app.maraiq.com)                                                                                  
  2. Click your avatar in the sidebar                                                                                          
  3. Select **Send Feedback**                                                                                                  
  4. Fill out the form and submit                                                                                              
                                                                                                                               
  Your submission will appear on the roadmap board.                                                                            
                                                                                                                               
  ## What Can I Submit?                                                                                                        
                                                                                                                               
  - **Bug Reports** — Something isn't working as expected                                                                      
  - **Feature Requests** — Ideas for new capabilities                                                                          
  - **Questions** — How do I do X?                                                                                             
  - **Data Issues** — Missing or incorrect information                                                                         
                                                                                                                               
  ## Privacy                                                                                                                   
                                                                                                                               
  - Only authenticated MARA users can submit feedback                                                                          
  - Personal details are not displayed publicly                                                                                
  - Only feedback content, type, and priority are visible on the roadmap                                                       
                                                                                                                               
  ## Questions?                                                                                                                
                                                                                                                               
  For account issues or urgent matters, contact support@maraiq.com.
